Multiplication Game

A bunny will poop one poop. When you get the multiplication in the poop right, the bunny will do another poop and you
have to get the answer right. You have ten minutes to get ten poops. If you don't get the answers in ten minutes you
have to start your level again with different multiplications.

The multiplications go from the one table to the 8 table. So it's from 1x1 to 8x12. On the bunny is written the number
of the table you are doing. The poops will disappear like if a human hand was picking it up with a purple and green bag.

When you finish all the levels you get a diploma.

Level 1: 1 table Level 2: 2 table
Level 3: 3 table Level 4: 4 table
Level 5: 5 table Level 6: 6 table
Level 7: 7 table Level 8: 8 table
Level 9: 1, 2, 3, 4 and 5 tables
Level 10: 1, 2, 3, 4, 5, 6, 7, and 8 tables.

The multiplications cannot be in order.
